A program that writes one short, funny rant about an everyday annoyance to `/output/entry.txt`. Node 22, stdlib only, fully deterministic — the rant is a fixed string constant in `main.ts`.

## The rant

> The self-checkout yelled 'unexpected item in the bagging area' at a bag of rice I hadn't even touched. I stood there, hands up like I'd robbed the place, while a teenager strolled over, tapped the screen once, and fixed in two seconds what the machine spent a minute accusing me of.

**Length: 282 characters / 282 bytes** (limit: 400 characters).

## Why it should win

Against the judge's five criteria, in order:

1. **A funny rant about an everyday annoyance** — it is exactly that: one specific incident at a self-checkout, not an essay or a list of complaints.
2. **Actually funny** — the joke is the reversal. The machine plays cop, the shopper is treated like a robbery suspect for buying rice, and the bored teenager is the real expert. The laugh comes from recognition, not from shouting.
3. **Specific and concrete** — one machine, one bag of rice, one quoted accusation, one teenager, one tap on the screen. No vague mood, no generic "technology is bad."
4. **Sharp, economical wording** — three sentences, each earning its place: the accusation, the humiliation, the rescue. No throat-clearing, no setup that goes nowhere.
5. **Freshness** — it dodges every cliché in the brief itself (broken printer, slow bus, Monday morning, "circling back"). The self-checkout's "unexpected item" is universally shared, but as a rant with a suspect-and-rescue arc it is an angle most entries will not take.

## Run it

```sh
node main.ts
```

Writes the rant to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
